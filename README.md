# Legal AI CSM Portfolio

我的法律 AI 产品型 CSM 面试作品集。

在线入口（GitHub Pages）：

https://woaiwangcai.github.io/legal-ai-csm-portfolio/

## 本地预览

```powershell
npm install
npm run dev
```

## 页面叙事

- 主案例：AI 合同审查与知识沉淀工具
- 产品链路：DOCX 解析 -> 知识路由 -> 规则约束 -> 模型审查 -> 可复核报告
- 评测维度：风险召回、引用准确性、误报率、人工复核率与失败兜底
- 客户成功：访谈、配置、培训、验收、反馈闭环
- 辅助证据：发票核算归档工具、PDF 扫描件拆分工作台

页面中的数字均来自个人实践材料，并按样本、时间范围和实践口径展示；不包含真实客户数据、真实合同、手机号、邮箱或 API Key。
